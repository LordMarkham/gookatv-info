# Privacy notice

GookaTV is a personal-use application. Updated 21 September 2026.

## Information used

The application accesses files and associated metadata selected or created by its user. Optional Google Drive integration stores and retrieves these files for synchronization.

## Access and storage

Google handles sign-in. The application requests access only to Drive files created by or explicitly made available to it, not the entire Drive. Authorization credentials are stored on the user's devices using operating-system protections. Material is stored locally and, when synchronization is enabled, in the user's Google Drive.

## Sharing

The application does not sell user data, use it for advertising, or transfer it to a developer-operated collection or analytics service. Data is sent to Google to provide the requested synchronization. Google processes that data under its own policies. This information page is hosted by GitHub, which may process ordinary web-request information.

## User controls

Google access can be revoked in Google Account settings. Disconnecting does not delete existing files. Cloud copies can be deleted through Drive; local copies and retained revisions must be removed separately. Local deletion or archiving does not necessarily remove cloud backups.

## Contact

Privacy questions can be sent through the [information-page issue tracker](https://github.com/LordMarkham/gookatv-info/issues). Do not post personal material or credentials.
